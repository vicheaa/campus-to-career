03 — Why internship

Why an internship matters

  • You learn how software is actually built, not just how code is written
  • You work with Git, code review, deadlines and people
  • You discover which kind of work you like — before committing
  • It's the most common door into a first full‑time role

In my case

Gained real-world experience working on actual projects and collaborating with a team of developers.

05 — Intern to full‑time

Turning an internship into a job

  • Ask questions early; ship something small, then something bigger
  • Be reliable — finish what you start and communicate blockers
  • Understand the product and the users, not only the code
  • Write things down: notes, docs, commit messages

07 — Learning

How I learn new technology in the AI era

  • Start with the official docs, then use AI to explain what confuses you
  • Build a small real thing — learning sticks when it's used
  • Ask AI to review your code and explain its suggestions, not just apply them
  • Keep fundamentals strong: HTTP, data structures, databases, Git
